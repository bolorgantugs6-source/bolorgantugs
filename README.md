# Bolor Gantugs (Krystal) — Vercel portfolio

## Deploy
1. Extract this ZIP. Upload the **contents** to a GitHub repository (not the ZIP).
2. Import it in Vercel with Framework: Other, Root: ./, Output Directory: public.
3. Connect `bolorgantugs.site` in Vercel Project → Settings → Domains. Follow the DNS records Vercel displays at your registrar.
4. Test all links and mobile navigation. No API keys or database required.

## Update book statuses
The book collection is **suggested, not verified as read**. Edit `public/index.html` book cards to reflect your actual readings.

## Evidence safety
Confidential recommendation letters and signed institutional letters are intentionally not distributed here. Link only public authorized documents. Verify claims and URL status before publishing.

## Photographs
Uses user-provided original photos; no AI-generated photographs.
